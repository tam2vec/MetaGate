# Capability Diff

The numeric score is useful for machines, but people need to see what changed.

```text
Metadata update applied
  Freshness assertion restored
  Column lineage mapping completed

AI impact
  Unlocked: Generate executive metrics
  Unlocked: Trust KPI
  Still blocked: Rename column
  Still blocked: Approve schema migration

Trust status
  Blocked -> Partially certified
```

This is the human-readable interpretation of the machine-readable Readiness
Diff in `examples/outputs/readiness-diff.json`.
