# Policy Catalog

Ready-to-use profiles are included for common adoption stages:

| Profile | Use it for | Strictness |
| --- | --- | --- |
| `discovery.yml` | Low-risk catalog exploration and lineage lookup | Low |
| `enterprise_ai.yml` | General enterprise AI assistance | Medium |
| `finance-production.yml` | Financial KPI explanations and summaries | High |
| `schema-change.yml` | Rename and migration approval workflows | Very high |

Each profile defines evidence weights, freshness limits, graph propagation,
and capability thresholds. Copy a profile and tune it for the team's risk
tolerance.
