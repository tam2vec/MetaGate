# Why Predicate?

| DataHub provides | Predicate adds |
| --- | --- |
| Metadata storage | Deterministic trust evaluation |
| Lineage graphs | Impact-aware capability gates |
| Ownership records | Evidence-backed action permissions |
| Assertions and incidents | Readiness gaps and remediation |
| A catalog experience | An AI admission contract |

DataHub remains the system of record. Predicate turns the metadata graph
into a decision about whether a particular AI action is safe to perform.
